# 0012. 금액은 원 단위 정수(long)

- 상태: 확정
- 날짜: 2026-11-26
- 이슈: 14-38

## 맥락

목표 금액, 참여 금액, 모인 금액, 상품 가격을 여러 사람이 다룬다.

## 결정

- 금액은 원 단위 정수다. Java `long`, DB `BIGINT`, JSON 숫자다.
- 금액 필드 이름은 `...Amount` 또는 `...Price`로 끝낸다. ArchUnit이 이런 이름의 필드가 `long`/`Long`이 아니면 막는다.

## 검토한 대안

| 대안 | 탈락 이유 |
|---|---|
| `BigDecimal` | 원화에는 소수점이 없어 이득 없이 다루기만 번거롭다 |
| `int` | 최대 약 21억이라 합계에서 넘칠 수 있다 |
| 문자열 | 계산과 비교가 어렵다 |

## 트레이드오프

- **얻는 것:** 계산이 단순하고 넘칠 걱정이 없다.
- **잃는 것:**
  - 금액인데 이름이 규칙과 다르면 검사를 빠져나간다.
  - 금액이 아닌데 이름이 `price`로 끝나는 필드는 이름을 바꿔야 한다.
  - 원화 외 통화는 다루지 않는다.
