# 0013. enum은 문자열로 저장

- 상태: 확정
- 날짜: 2026-11-26
- 이슈: 14-38

## 맥락

입금 상태(입금 전, 확인 대기, 확인 완료, 반려), 문의 답변 상태, 펀딩 유형 같은 상태값이 많다.

## 결정

- 엔티티의 enum 필드는 `@Enumerated(EnumType.STRING)`, 컬럼은 `VARCHAR`다.
- ArchUnit이 막는다: 엔티티·임베더블의 enum 필드에 `@Enumerated(EnumType.STRING)`이 없는 경우. 애노테이션을 빠뜨려 기본값인 순서값으로 저장되는 경우도 포함한다.

## 검토한 대안

| 대안 | 탈락 이유 |
|---|---|
| 순서값(`ORDINAL`) | enum 순서를 바꾸거나 중간에 값을 넣는 순간 저장된 데이터의 의미가 바뀐다 |
| PostgreSQL enum 타입 | 값을 추가하거나 바꿀 때마다 타입 변경 마이그레이션이 필요하고 Hibernate 매핑이 번거롭다 |

## 트레이드오프

- **얻는 것:** DB를 직접 봐도 의미가 보이고, 순서를 바꿔도 안전하다.
- **잃는 것:**
  - 저장 공간이 조금 더 든다.
  - enum 이름을 바꾸려면 데이터 마이그레이션이 필요하다.
  - DB에는 허용 값 제약이 없다. 필요하면 `CHECK` 제약을 건다.
